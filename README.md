# Voluntary Claim Record — non-sworn development

**Selected path: non-sworn Claim Record. Current stage: synthetic Phase 0 only.**
The owner authorized this direction on September 5, 2026. Development continues PR #5's existing branch, `proposal/non-sworn-claim-record-v1`. See the [owner decision](audit/OWNER_DECISION_2026-09-05.md) and [document hierarchy](audit/CANONICAL_STATUS.md).

The format keeps a person's bounded statement, stated basis and qualifications together with a separately attributed editorial assessment and correction history. It adds no program oath, notarial verification or penalty-of-perjury mechanism. Participation indicates willingness to document a claim; it is not a validated confidence or honesty measure.
